How to get your JanitorAI token

Your session token allows the exporter to read your characters, private bots, and lorebooks without saving or logging anything.

  1. Log into janitorai.com in your browser.
  2. Press F12 (or right-click and select Inspect).
  3. Go to the Application tab (or Storage in Firefox).
  4. Expand Local Storage on the left and select https://janitorai.com.
  5. Find the key named sb-mcmzxtzommpnxkynddbo-auth-token.
  6. Copy the access_token string (starts with eyJ...) and paste it into the token box.
